# PracticeProblems01-02
//Objective
The objective of this program is to check whether a username is available or already taken.
It also suggests similar usernames and tracks the most attempted username using HashMap.

//Flow of Project
Store existing usernames in a HashMap.
User enters a username.
System checks if the username exists.
If taken → show not available + suggestions.
If not taken → show available.
Track how many times usernames are searched.

//Running Procedure
Open Java IDE.
Create class PracticeProblems01_02.
Paste the given code.
Compile and run the program.
Check the output in the console.
